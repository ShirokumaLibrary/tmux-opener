PlemolJP Console HS — copyright and license
===========================================

The font files bundled with this extension are PlemolJP Console HS Regular
(fonts/PlemolJPConsoleHS-Regular.ttf) and PlemolJP Console HS Bold
(fonts/PlemolJPConsoleHS-Bold.ttf), made and distributed by Yuko Otawara in the
PlemolJP project under the SIL Open Font License, Version 1.1. Both come from
the same distribution (PlemolJP_HS_v3.0.0.zip) and are bundled unmodified, and
everything stated below covers both of them. PlemolJP is composed from IBM Plex
Mono and IBM Plex Sans JP (the upstream project states this), and the bundled
faces' own copyright field credits four parties -- IBM Plex, Hack, Nerd Fonts
and PlemolJP -- which is what section 1 quotes.

Which source states what is kept separate on purpose: a license file's whole
value is that its claims can be checked against the primary documents, so a
paraphrase must not be presented as a quotation. The primary documents this file
refers to ship in this package, under licenses/ (section 3).

1. Copyright holders, quoted verbatim
-------------------------------------

The bundled TTFs' own `name` table, nameID 0 (copyright), reproduced exactly --
identical in the Macintosh (platform 1, encoding 0, language 0x0) and Windows
(platform 3, encoding 1, language 0x409) records, and byte-for-byte identical
between the regular and the bold face (measured: each record hashes the same in
both files -- the Mac and the Windows record differ from each other, as their
encodings require -- so this one quotation covers both faces). The TTFs are
bundled unmodified, so this is the machine-readable copyright field OFL
section 2 speaks of:

    [IBM Plex]
    Copyright (c) 2017 IBM Corp. https://github.com/IBM/plex

    [Hack]
    Copyright 2018 Source Foundry Authors https://github.com/source-foundry/Hack

    [Nerd Fonts]
    Copyright (c) 2014, Ryan L McIntyre https://ryanlmcintyre.com

    [PlemolJP]
    Copyright (c) 2021, Yuko Otawara

The upstream project's own LICENSE file (v3.0.0, section 「"PlemolJP"
licensing」) states the PlemolJP holder again, there with a Reserved Font Name:

    Copyright (c) 2021, Yuko OTAWARA. with Reserved Font Name "PlemolJP"

RESERVED FONT NAME: the line above reserves the name "PlemolJP" (OFL
section 3), and licenses/LICENSE_IBM-Plex reserves "Plex" the same way. Nothing
here triggers either clause -- both TTFs are bundled unmodified and the family
name they declare (PlemolJP Console HS) is the upstream one -- but a *modified*
version of this font may not be distributed under a name containing those
reserved names.

2. The OFL declaration this font software carries

The bundled TTFs' `name` table, nameID 13 (license description), reproduced
exactly -- again identical between the Macintosh and the Windows records and

    This Font Software is licensed under the SIL Open Font License,
    Version 1.1. This license is available with a FAQ

The full OFL 1.1 text follows at the end of this file, copied verbatim from that
upstream LICENSE file.

3. License texts
----------------

The distribution archive PlemolJP_HS_v3.0.0.zip contains font files only: it
carries no license and no README entry (measured -- zero such entries). The
primary license documents are therefore taken from the upstream repository at
its v3.0.0 tag, with their sha256 recorded in this package's README, and ship
here under licenses/:

    licenses/LICENSE_IBM-Plex    upstream source/LICENSE_IBM-Plex
    licenses/LICENSE_Hack        upstream source/hack/LICENSE
    licenses/LICENSE_NerdFonts   upstream source/LICENSE_NerdFonts

They are shipped in full rather than cited, because two of them carry MIT
permission notices, and MIT's condition is that "The above copyright notice and
this permission notice shall be included in all copies or substantial portions
of the Software" -- a copyright line alone does not answer it. Read each
document for what it actually says rather than through a summary; two points
are worth stating because they are easy to get wrong:

- In Nerd Fonts, the fonts themselves are under the OFL and the MIT License
  covers the project's source code files (licenses/LICENSE_NerdFonts states
  which is which). It is not "an MIT font", and grouping it with Hack under one
  "MIT components" heading would misstate both: in the Hack project it is the
  font work that is MIT-licensed.
- licenses/LICENSE_Hack is not limited to Hack. The same document also states
  the DejaVu project's public-domain dedication and reproduces the Bitstream
  Vera License (with the Reserved Font Names "Bitstream" and "Vera"), so it
  speaks for more parties than the one named in section 1.

Note this file covers the *font*. It is also this extension's license: the
extension carries no code beyond a no-op activate/deactivate stub, so there is
nothing else to license separately.

4. A note on the OFL declaration and the MIT text in licenses/LICENSE_Hack
--------------------------------------------------------------------------

Two quotations in this file look, at first reading, as though they contradict
each other. Section 2 quotes the upstream LICENSE saying "Source fonts are
licensed under SIL OPEN FONT LICENSE Version 1.1", while licenses/LICENSE_Hack
opens with "The work in the Hack project is Copyright 2018 Source Foundry
Authors and licensed under the MIT License". Both are reproduced as they stand,
and neither is amended here; what differs is their subject.

The first is a statement about *this* font software -- the PlemolJP fonts this
package ships, whose nameID 13 says the same thing (section 2). The second is
the primary document of one *upstream component*, describing the terms of the
Hack project on its own side. A component distributed under permissive terms
can be composed into a font released under the OFL, which is what the upstream
project states it did; the component's own document keeps its own terms, and
this package ships it (section 3) precisely so a reader can check that reading
against the source rather than take this paragraph's word for it.
